# Instruções do projeto

- Implementar somente a tarefa solicitada.
- Priorizar simplicidade e recursos nativos do Django.
- Evitar dependências e abstrações desnecessárias.
- Executar verificações após cada implementação.
- Atualizar o planejamento após concluir uma tarefa.
- Aguardar a aprovação do usuário antes de avançar para a próxima tarefa.

## Contexto

Portal de processos seletivos para cursos de especialização da UFT, começando pela Especialização em Gestão de Incêndios Florestais.

Stack prevista: Django, Django Templates, Tailwind CSS com daisyUI e SQLite inicialmente, com possibilidade de migração para PostgreSQL.

Usar componentes do daisyUI na interface e classes utilitárias do Tailwind CSS para ajustes de layout e estilo, priorizando consistência visual e evitando CSS personalizado desnecessário.

## Forma de trabalho

- Consultar `PLANEJAMENTO.md` antes de iniciar uma tarefa.
- Manter as tarefas pendentes até que sua implementação e verificação estejam concluídas.
- Registrar no planejamento as verificações executadas e eventuais pendências.
- Não presumir regras de edital: confirmar os requisitos antes de implementar critérios de inscrição, avaliação ou classificação.
